# Installation

1. Télécharge `BE_STRONGER_V25.zip`.
2. Dans **Fichiers > Téléchargements**, touche le ZIP.
3. Ouvre le dossier `BE_STRONGER_V25`.
4. `index.html` = application client.
5. `coach.html` = espace coach.
6. Le logo est déjà inclus dans `assets/be-stronger-logo.png`.

Pour GitHub Pages, envoie tout le contenu du dossier en conservant le dossier `assets`.
